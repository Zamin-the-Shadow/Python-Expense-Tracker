# Python Expense Tracker
A simple Python-based Expense Tracker application that allows users to enter multiple expenses and calculates the total amount spent.
## 📌 Project Overview
This project was created as part of Python Programming training at DecodeLabs. The main objective of this project is to understand:
- Mathematical operations
- Accumulator logic
- User input handling
- Loops in Python
- Real-time data processing
The program continuously accepts expense amounts from the user and displays the final total when the user finishes entering data.
---

## 🚀 Features
- Add unlimited expense entries
- Automatically calculates total expenses
- Simple and beginner-friendly Python project
- Uses accumulator pattern for calculations

## ▶️ How to Run

2. Clone this repository:
```bash

```
3. Open the project folder

4. Run the Python file:
```bash
python Project2.py
```
